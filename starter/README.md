# Starter theme

A complete, valid Den theme with plain values. Copy this directory, then:

1. Set `id` (lowercase letters, digits, dashes), `name`, `author` and `description`.
   If the theme lives in `themes/<id>/` of a repo like this one, the directory name must equal `id`.
2. Change the colors in `modes.light` and `modes.dark`. Both modes are required.
3. Replace `mark.svg` with your own mark (an SVG file: no scripts, no external references).
4. Optionally add fonts: put the `.woff2` files and their license under `fonts/<family>/`
   and list them in `fonts`.
5. Run the validator and fix what it reports.

See the README at the root of this repo for every field and rule.
